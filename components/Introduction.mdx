# Eric Blanchard: component library

These are the building blocks of [the portfolio site](/). Every story here is also a test:
the pipeline renders each one in Chromium, runs its interaction checks, and fails the build on
any accessibility violation found by axe.

## Principles

- **Static first.** Components are Server Components unless they need the browser. None of them do yet.
- **Content is data.** Projects live in `content/projects.ts`, typed, and validated by unit tests.
- **One bold thing per page.** The display type and the hex map carry the personality; everything else stays quiet.
